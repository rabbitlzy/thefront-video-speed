# 学习视频 1.5 倍速插件

适用于 Windows 上的 Chrome 和 Edge。默认在 `https://bit.thefront.cn/` 的 HTML5 视频上应用 1.5 倍速，切换视频和刷新页面后继续使用已保存的设置。

## 安装（无需编译）

1. Chrome 地址栏输入 `chrome://extensions`；Edge 输入 `edge://extensions`。
2. 打开「开发者模式」。
3. 点击「加载已解压的扩展程序」（有些版本称为「加载解压缩的扩展」）。
4. 选择本项目文件夹，即包含根目录 `manifest.json` 的目录。如果从 GitHub 下载 ZIP，请先解压，再选择解压后的项目文件夹。
   （原来的 `video-speed` 子文件夹也可以独立加载，二者只需安装一个。）
5. 返回课程页面并刷新，点击播放，即会自动应用 **1.5 倍速**。

点击浏览器工具栏中的「扩展」→「学习视频 1.5 倍速」，可以选择 1 / 1.25 / 1.5 / 1.75 / 2 倍速。选 1.0 恢复原速；取消「启用自动倍速」会恢复当前视频被插件接管前的速度，并停止自动调整。直接停用或移除整个扩展后，请刷新课程页。

## 兼容性与实现范围

- 只申请本地设置存储权限，仅在上述域名及其匹配的嵌入框架中自动运行，无外部依赖，不上传数据。
- 调整 HTML5 video 的 playbackRate 和 defaultPlaybackRate，保留浏览器默认的音调处理。不自动播放、不跳转视频、不修改学习时长或完成记录。
- 支持动态加入的视频、同域 iframe 和开放的 Shadow DOM。来自其他域名的 iframe、封闭 Shadow DOM 或专用播放器可能无法处理；目前未取得登录后页面进行实测。
- 如果无效果：确认扩展已启用、安装后已刷新课程页、弹窗选择 1.5。若仍无效，需要进一步查看实际播放器结构。
- 网站如何记录学习进度取决于平台自身，本插件不保证倍速观看会按原时长计入进度。

内容脚本的框架匹配采用 [Chrome 官方文档](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts) 中的配置。

## 开发验证

在项目根目录运行 `node tests/content.test.cjs`（需要 Node.js）。这些是模拟媒体元素的逻辑测试，不能代替目标网站的实际播放验证。
